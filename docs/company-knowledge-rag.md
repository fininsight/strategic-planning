# 핀인사이트 회사자료 RAG 운영 메모

## 파일 위치

로컬 개발에서는 회사소개서, 주요 수행실적, 인력/조직 정보, 보유 기술/솔루션 자료를 아래 폴더에 넣는다.

```text
.local-data/company-knowledge/sources/
```

`.local-data/`는 gitignore 대상이라 회사 내부 자료가 저장소에 커밋되지 않는다. 운영 서버에서는 `COMPANY_KNOWLEDGE_DIR` 환경변수로 서버 스토리지, NAS, EFS, S3 마운트 경로 등을 지정한다.

```bash
COMPANY_KNOWLEDGE_DIR=/data/fi/company-knowledge
```

## 현재 지원 파일

현재 1차 RAG는 기존 텍스트 추출기를 재사용하므로 `pdf`, `hwp`, `hwpx`, `txt`, `md`, `html`, `xml`을 지원한다. 회사소개서가 `pptx`, 수행실적이 `xlsx`, 조직도가 `docx`라면 PDF로 저장해서 올리는 방식이 가장 안정적이다.

## 사용 흐름

1. 회사자료를 `sources/` 폴더에 업로드한다.
2. 전략수립의 시장·경쟁 리서치를 실행한다.
3. 백엔드가 첫 실행 시 `index.json`을 자동 생성한다.
4. 공고 첨부파일 분석 내용과 평가항목으로 회사자료를 검색한다.
5. 검색된 근거가 웹검색 프롬프트의 `companyEvidence`로 들어간다.
6. 외부 시장 수치, 법령, 고시번호, 점유율, 수주사실은 웹 출처 링크가 있는 경우에만 `verified`로 표시된다.

## 원칙

- 회사자료 RAG는 핀인사이트 강점과 내부 증빙을 찾는 용도다.
- 시장 규모, 성장률, 수주사실, 법령, 고시번호는 반드시 웹검색 출처 링크가 있어야 제안서에 사용할 수 있다.
- 회사자료에 없는 인증, 실적, 솔루션 기능은 추정하지 않고 `필요 증빙`으로 남긴다.
